# 🩸 Blood Bank Management System

A full-stack CRUD web application built with PHP, MySQL, Bootstrap and XAMPP.

## 🔗 Tech Stack
- Frontend: HTML, CSS, Bootstrap 5
- Backend: PHP (Core PHP)
- Database: MySQL via phpMyAdmin
- Server: XAMPP (localhost)

## ⚙️ How to Run
1. Install XAMPP and start Apache + MySQL
2. Copy project folder to `C:/xampp/htdocs/blood-bank-system`
3. Import `blood_bank.sql` in phpMyAdmin
4. Open `http://localhost/blood-bank-system`
5. Login: admin@bloodbank.com / admin123

## 📁 Modules
- 🏠 Dashboard
- 🧑 Donors (Full CRUD)
- 🩸 Blood Stock Management
- 📋 Blood Requests
- 💉 Transfusion Records
